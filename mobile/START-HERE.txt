BOARDLENS MOBILE 1.6 / DESKTOP 2.15 — NOVEMBER 11, 2026

One companion app. Phone analysis is a feature in its menu and uses the same
colors, typography, buttons and spacing as the computer companion.

COMPUTER
Desktop → Phone → Enable companion. Connect over the same Wi-Fi with the
computer address and six-digit code. Settings sync with the desktop and save.

PHONE ANALYSIS
Open Phone in the companion menu, or On this phone from the start screen.
Press Start, allow sharing the entire display, and allow arrows over other
apps. Press Home or Open another app. A visible foreground-service notification
keeps the user-started session running while the interface is in the background.
Use Stop in the app or notification to end it. Force-stop, revoked permission,
protected screens, device locking or OS restrictions can interrupt capture.
Screen sharing is never silently restarted after the OS ends the session.

Stockfish runs locally on Android 10+ / arm64. Its optional 99 MB evaluation
file downloads only when selected. Computer mode uses the paired computer's
Maia 2, Maia 3, Tiny bots or other installed engines. Only the recognized
position is sent, never the phone screenshot. The computer must stay running.
Phone analysis settings are separate from settings for the computer's boards.

ENGINE CONTROLS
Search engines: select time, depth, or the first of both limits. The evaluation
bar has an independent engine. Manual means individual settings, not a preset.
Show moves while thinking displays the first useful result before completion.
Predict replies adds possible later moves. Prediction length counts plies:
3 = your move, opponent reply, your response. The reply budget limits extra
passes after the first recommendation; it is not an artificial delay.
Maia 2 and all Maia 3 sizes predict one move per pass. They do not have a native
search-depth setting. An in-progress model pass may finish after the reply
budget. Tiny bots use their coded search depth and an adjustable clock budget.

BOARD RECOGNITION
The whole supported board must be visible. Pixel recognition is not universal.
The new context model and projected geometry are experimental for 3D piece
artwork; not every 3D style, camera angle or theme is verified. Visually hidden
or indistinguishable pieces cannot be recovered from pixels alone. See the
recognition coverage report for exact synthetic and Android fixture results.
