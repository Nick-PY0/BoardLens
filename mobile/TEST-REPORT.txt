MAIA PERFORMANCE AND TIME CONTROLS — ANDROID 1.8.3
All four Maia move models show the same saved thinking-time control. For Maia,
the budget starts before the main inference and limits additional reply passes.
The first pass is always delivered, even if it exceeds the budget; an in-flight
reply may finish after the deadline. No repeated identical inference, arbitrary
wait, deeper-search claim or automatic engine/model switching is added. Maia
evaluation still uses one value pass and has no fictitious search-time field.

Selected Maia weights/vocabulary are prepared on the engine worker while the
scanner starts. A bounded LRU cache keeps 64 immutable, complete move rankings,
keyed by model, encoded rating, threads and full FEN. It supports different
alternative counts and reuses positions previously evaluated for prediction.
Close clears the cache and session. ONNX idle thread spinning is disabled to
reduce contention with recognition/evaluation when multiple threads are used.
The official model files, hashes, policy order and values are unchanged.

The real-model before/after host benchmark used seven repeated searches per
model with different alternative counts. Median repeat times on the Mac host:
  Maia 2:      4.430 ms before; 0.007 ms with a cache hit
  Maia 3 5M:   7.417 ms before; 0.008 ms with a cache hit
  Maia 3 23M: 16.242 ms before; 0.006 ms with a cache hit
  Maia 3 79M: 29.552 ms before; 0.007 ms with a cache hit
These are cache-hit/component times, not new-position inference speedups or
phone screen-to-arrow timing. First cold loads still took roughly 100–800 ms
on this host; preparing them overlaps scanner startup rather than eliminating
the work. Larger models still cost more for uncached positions.

Tests verify all four timer fields save, preserve the independent evaluator
and leave search-depth preferences intact. Controlled-clock real-model tests
verify budget exhaustion still publishes the main move, extra budget permits
replies, an actual predicted position needs no new inference, a changed rating
