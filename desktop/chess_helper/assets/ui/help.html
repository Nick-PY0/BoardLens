BoardLens Help

Getting started · Start reading a board

Choose Computer screen, keep the whole board visible, then use Scan now. Auto suggest follows later moves.

  1. Board → Read from → Computer screen.
  2. Choose Display to read. All displays checks every connected monitor.
  3. Keep all 64 squares visible and move BoardLens away from the target.
  4. Press Scan now. Enable Auto suggest to follow moves.

Screen reading and engine thinking are separate. Use the separate connections for supported 3D boards.

Getting started · The board is not being found

Scan now starts a fresh read. Check the selected display, whether the board is covered, and whether a target lock is keeping an old board selected.

  1. Check Board → Display to read.
  2. If Keep this board selected is on, return to that board or turn it off.
  3. Keep the whole board visible. Scan now clears old recognition and releases a locked suggestion.
  4. For supported themes or 3D views, try the Browser connection or Local 3D chess connection.

Pixel recognition supports known 2D artwork. Arbitrary 3D screenshots are not supported. OS screen-recording permission is needed for pixels.

Getting started · Scan now and Auto suggest

Scan now refreshes from the visible board immediately. Auto suggest keeps reading and requesting new analysis after moves.

  1. Use Scan now after switching games or when a position is stale.
  2. Use Auto suggest for continuous tracking.
  3. Keep this board selected stays active during a rescan; turn it off if you want a different target.

Scan now cancels obsolete reads and analysis. It never clicks a move in the real game.

Getting started · Stop scanning and thinking

STOP cancels live reads and engine searches, then hides screen overlays.

  1. Press STOP, Escape while the main window is active, or the configured Stop shortcut.
  2. Use Auto suggest or Scan now to start live reading again.

Previous/Next pauses live tracking for history navigation.

Boards and connections · Choose where the position comes from

Practice is a local board you can edit. Computer screen follows another visible app. Screenshot reads a file you choose.

  1. Practice board: click pieces or load a FEN.
  2. Computer screen: choose a display and scan.
  3. Screenshot: choose Open screenshot, then a complete supported 2D board image.

Orientation controls which color appears at the bottom. Side to move corrects uncertain live turn detection.

Boards and connections · Screen scanning or an optional connection?

Standard 2D boards can use screen scanning alone. Browser and Local 3D chess are separate optional ways to read supported apps directly.

  1. Use Computer screen for supported flat 2D boards.
  2. Use Browser connection for supported Chess.com/Lichess positions and themes.
  3. Use Local 3D chess for the built-in macOS Chess app.

A connection being off does not disable the other reading methods. Local 3D chess currently supports macOS Chess.app, rather than every 3D chess program.

Boards and connections · Connect the browser

Turn on Connect browser to reveal its status and pairing controls. One pairing key connects the optional local extension.

  1. Board → Computer screen → Optional connections → Connect browser.
  2. Connection setup explains loading BoardLens 2/BrowserReader in Chrome or Edge.
  3. Copy pairing key. Paste it into the extension popup and choose Connect.
  4. Reload the chess tab and keep it visible.

The loopback service uses port 8788. Positions stay on this computer. The extension cannot play moves or change settings. Browser data can preserve more metadata than a screenshot.

Boards and connections · Repair a disconnected browser

The extension retries temporary interruptions. Its status distinguishes a missing key, an offline desktop, and an invalid pairing.

  1. Keep Connect browser enabled in BoardLens.
  2. If the key is rejected, copy the current key into the extension and reconnect.
  3. After an extension update, reload the extension once and reload the chess tab.
  4. Keep the chess tab visible; switching away normally releases its feed.

The browser pairing key survives desktop restarts. This differs from the phone code, which changes when its companion restarts.

Boards and connections · Read Local 3D chess

Local 3D chess reads the built-in macOS Chess app through Accessibility, independently of the browser connection.

  1. On Mac, enable Read local 3D chess in Optional connections.
  2. Grant BoardLens/Python Accessibility in System Settings → Privacy & Security.
  3. Open the local Chess board and press Scan now.

Its status says Ready until its supported app is active, then Connected after a board is read. Other local 3D programs and arbitrary camera/artwork screenshots are not covered.

Boards and connections · Keep one board selected

Keep this board selected prevents other apps or boards from replacing your target. A covered or missing target pauses instead of switching.

  1. Read a live board first. If several are present, choose the target in Board.
  2. Turn on Keep this board selected.
  3. Turn it off to follow other apps again.

Pixel targets remain at their captured area; unlock and rescan after moving/resizing them. Direct readers keep their source identity. Overlays hide when another app covers a locked target.

Boards and connections · Analyze several boards

Up to three boards have independent positions, engine sessions and recommendations.

  1. Show complete boards on your selected displays.
  2. Use Scan now to discover them.
  3. Use Boards to see their cards together, or Focus for the primary board.

Cards disappear when boards are no longer detected. New-board discovery also runs periodically. Each engine session adds its own thread and memory usage.

Boards and connections · Your color and whose turn it is

Only my color treats the color at the bottom as yours. Side to move is a separate control for uncertain live positions.

  1. Enable Only my color for suggestions on your turns only.
  2. Board → Detect bottom color normally handles orientation automatically.
  3. On a static live position, set Side to move to White or Black if needed.

Only my color forces automatic orientation. A screenshot/DOM read may lack complete castling, en passant or turn history. A full FEN on Practice preserves exact metadata.

Engines · Choose an engine

Analysis engine selects the recommendation provider manually. The Engine library manages optional downloads.

  1. Open Engine → Engine library.
  2. Choose the engines to download; large neural models are optional.
  3. After installation, select the engine in Analysis engine.

Selecting an unavailable engine gives a setup message. BoardLens never downloads or switches engines silently. Installed engines are skipped in download batches.

Engines · Maia human-style predictions

Maia-2 and Maia-3 predict human choices at a target rating. They do not use Stockfish search depth or time limits.

  1. Download the chosen Maia entry in Engine library.
  2. Select it manually and set Human target rating.
  3. Request suggestions normally.

No separate reinstall button is needed. Its scores are human-game outcome estimates, not objective Stockfish evaluations or guaranteed playing Elo. Maia-2 uses Rapid rating bins; models need their optional runtime and weights.

Engines · Stockfish skill and Elo

Full strength searches without a strength limit. Skill level and Elo rating deliberately change its selected recommendation.

  1. Choose Stockfish.
  2. Set Stockfish strength to Full strength, Skill level or Elo rating.
  3. Adjust the active skill/Elo control.

The supported Elo range depends on the installed Stockfish build. #1 is its strength-limited choice; alternatives can have better objective scores. The evaluation bar uses the strongest searched evaluation.

Engines · Think time, depth and adaptive limits

Time sets seconds of thinking. Depth sets a search depth. Time + depth stops at the first limit. Adaptive stays under both caps.

  1. Time: use seconds only.
  2. Depth: use a fixed depth; elapsed time can vary widely.
  3. Time + depth: whichever limit is reached first stops the search.
  4. Adaptive: reduce time/depth based on move count, checks and captures.

Stop cancels thinking. Maia uses a model pass; Tiny bots support their own timed move choice, not full Stockfish depth analysis.

Engines · Make suggestions arrive sooner

Screen refresh targets 75 ms independently of engine think time. Early suggestions can display intermediate results while the full search continues.

  1. Use Early suggestions to see an early result.
  2. For a faster completed search, reduce Think time yourself or choose a shallower supported limit.
  3. Use fewer suggested moves and suitable threads per board to reduce work.

The 75 ms screen interval is fixed, not a guaranteed move-to-arrow delay. Capture permission, recognition, engine startup and drawing add latency. Direct connections bypass artwork recognition.

Engines · Threads and memory

CPU threads and hash memory apply per analyzed board. More is not always faster on a busy computer.

  1. Set CPU threads to the number you want per engine session.
  2. Set Hash memory for the engine’s position cache.
  3. Remember that three boards and engine comparison start separate searches.

Maia and Tiny bots do not expose all of these Stockfish controls.

Engines · Playing styles

Balanced keeps the native recommendation. Other supported styles rerank close candidates using visible tactical and positional facts.

  1. Choose an engine with style support.
  2. Select Balanced, Aggressive, Defensive, Human-like or Maximum strength.
  3. Use Maia when you want a model trained on human decisions.

These styles do not rewrite an engine’s internal evaluation. Tiny bots keep their coded behavior. Maximum strength removes Stockfish’s skill/Elo limit.

Engines · Tiny bots, Flounder and custom UCI

Tiny bots choose one move without detailed evaluation or alternatives. Flounder samples Stockfish-derived choices; custom UCI uses an executable you supply.

  1. Read the selected engine’s capability note.
  2. For Tiny bots use one suggestion; download its shared .NET runtime through Engine library.
  3. For Custom UCI choose its executable in Engine files.

Reference Elo is not guaranteed at your search budget. Flounder’s target rating is approximate. Custom multiple recommendations require MultiPV support.

Engines · Compare engines side by side

Comparison runs two or three chosen engines on the same position without changing your main engine.

  1. Expand Compare engines in Engine.
  2. Choose engines A and B; choose C or None.
  3. Press Compare engines.

Each comparison keeps its own results and errors. Human estimates and objective engine evaluations are labelled separately.

Engines · Save and load a named preset

Presets store engine and display choices. Quick analysis and Deep analysis are built in.

  1. Configure the engine and arrows.
  2. Use Save preset and enter a name.
  3. Choose a saved preset to load it; Manage renames, updates or removes custom entries.

Presets include limits, strength, style, move count, arrow filters and threats. They exclude screen refresh, display choice, connection keys and readers. Missing engines must be installed first.

Settings and shortcuts · Settings save automatically

Your preferences save after a short editing pause and when you close BoardLens. Installed engines live outside the app folder.

  1. Finish editing a value and wait briefly.
  2. Save now writes immediately.
  3. Apply keybinds activates shortcut edits.
  4. Keep the application-data folder when updating the application.

Phone changes sync to desktop and then save. Invalid unfinished shortcut text is not saved. Your selected analysis preset is preserved.

Arrows and evaluation · Arrow colors and alternatives

Gold is #1, blue is #2, and later colors are more alternatives. Cyan is the opponent’s best reply after #1.

  1. Choose Suggested moves in Engine.
  2. Use Arrows → Moves to draw and rank filters to control visibility.
  3. Opponent reply shows a continuation after the best move, not a second move for the current turn.

Only my color, Lock move and color/rank filters can intentionally hide arrows. Rank labels identify alternatives. Dashed reply is optional; solid is the default.

Arrows and evaluation · Stop suggestions flickering

Steady arrows smooths intermediate replacements while analysis continues. Lock move keeps the first displayed move until the position changes.

  1. Use Steady arrows to keep calculating with fewer visible changes.
  2. Use Lock move when you want one fixed recommendation for the current position.
  3. Changing the board or pressing Scan now releases that locked suggestion.

Evaluation still updates. The first hint and completed engine result are immediate; provisional replacements need to remain consistent briefly.

Arrows and evaluation · Screen arrows let clicks through

Screen overlays are passive. You should still be able to move pieces in the target app with arrows visible.

  1. Toggle Arrows in the top bar, Screen arrows in the Arrows tab, or the arrow shortcut.
  2. This changes screen overlays without stopping monitoring or engine thinking.

The mirrored board and phone can still show their own hints. Covered or unconfirmed target boards may hide screen overlays temporarily.

Arrows and evaluation · Read the evaluation bar

Positive values favor White; negative values favor Black. M means the engine found a forced mate. The bar is not a winning percentage.

  1. Read the signed score next to the board. +1.00 is roughly a pawn-sized engine advantage for White.
  2. A neutral dash means there is no supplied evaluation yet.
  3. Use Full analysis for the complete explanation and variations.

Strength-limited suggestions and Maia predictions are labelled. Maia scores describe human-game outcomes; Tiny bots do not supply an evaluation.

Arrows and evaluation · Threat highlights

Red rings mark possible material loss in legal capture exchanges. Purple rings mark mate-in-one targets for the side to move.

  1. Arrows → Threats → Threat highlights.
  2. Show attacked squares adds dots for the opponent of the bottom color.
  3. Show mate-in-one targets enables purple targets.

These bounded capture checks are estimates. They do not prove every tactic or assess all sacrifices. Hover the mirrored board for explanations.

Practice and history · Review previous live positions

Previous and Next browse observed positions while live reading pauses. Resume live returns to the current target.

  1. Use Previous/Next below the mirrored board.
  2. Resume live returns to current play.
  3. On Practice, Undo removes a local move.

History never undoes moves in another app. Resume live to continue following your current board.

Practice and history · Use the local Practice board

Practice is an editable board inside BoardLens. It never controls the external game.

  1. Board → Read from → Practice board.
  2. Click a piece, then its destination. Click promotion chooses a queen.
  3. Suggest requests analysis; Play best makes exactly one local move.
  4. New game resets the local board; Undo takes back a local move.

Practice moves stay inside BoardLens. External boards receive suggestions only.

Practice and history · Load and copy a FEN position

FEN describes one exact chess position, including whose turn it is.

  1. Load FEN on Practice for exact turn, castling and en passant metadata.
  2. Copy FEN shares the current position.

Invalid FEN is rejected. Pixel reads cannot recover every historical right from artwork alone.

Settings and shortcuts · Keyboard shortcuts

Keys configures shortcuts for suggestions, scanning, overlays, history, Stop and one local Practice move.

  1. Enter pynput notation such as <ctrl>+<alt>+s or <cmd>+<shift>+b.
  2. Use Apply keybinds to validate and activate all entries.
  3. Global shortcuts work outside BoardLens when OS permissions allow them; otherwise use focused-window shortcuts.

Default Ctrl+Alt keys: S Suggest, A Auto suggest, B Scan, H Arrows, X Stop, Left/Right History, L Resume, M one Practice move. Escape stops while the main window is active.

Settings and shortcuts · Compact, full analysis and staying on top

Compact prioritizes the board. Expanded keeps settings beside it. Full analysis gives the workspace to the explanation.

  1. Use Compact/Expand in the top bar.
  2. In Compact, Settings opens the same tabs in a separate window.
  3. Full analysis expands the text; Text − / + changes its size.
  4. Stay on top keeps the desktop window above other windows.

Compact resizing retains the current display and position when possible. Settings content wraps and scrolls vertically.

Phone and tablet · Pair a phone or tablet

Enable the desktop companion, use the same network, then enter its computer address and six-digit code on your phone.

  1. Desktop → Phone → Enable phone companion.
  2. Open the Android companion or the shown address in a phone/tablet browser.
  3. Enter the six-digit code.
  4. Start with BoardLens enables the companion automatically on desktop startup.

The computer must stay awake and running; minimizing its GUI is fine. The connection port can be changed before enabling the companion. iOS native source still needs your signing setup.

Phone and tablet · Phone settings sync to desktop

Phone edits are sent after a short typing pause, reflected in desktop controls and saved there.

  1. Wait for Synced with your computer.
  2. Apply now retries an interrupted edit.
  3. Paths sync after editing finishes; keyboard shortcuts have their own Apply button.

If a desktop modal dialog is open, close it before remote edits. Disabled settings reflect the selected engine’s capabilities.

Phone and tablet · Reconnect the phone

After the companion restarts, pair again with its new code. Keep the desktop running on the same reachable network.

  1. Check the address in the desktop Phone tab.
  2. Keep the companion enabled and the computer awake.
  3. Check Wi-Fi and local firewall access.
  4. Enter the current six-digit code.

The phone code differs from the persistent browser-extension key. A local address is not reachable from arbitrary internet connections.

Settings and shortcuts · Copy buttons

Copy buttons show Copied to clipboard when text is available. An empty value reports that there is nothing to copy.

  1. Use a Copy button for a position, configuration or pairing value.
  2. Paste the text into the app or field where you need it.

The clipboard belongs to the device where you tapped Copy. The phone reports a browser clipboard restriction if copying fails.

Settings and shortcuts · Update BoardLens from GitHub

Check for updates manually in Board → App. Android has its own app-update button.

  1. Desktop: Board → App → Check for updates.
  2. If a newer desktop build is available, choose Download and restart.
  3. Android: Check for app updates on the connection screen, or Controls → Update Android app.
  4. Confirm an Android installation in the system installer; grant installation access only if you want that update.

Downloads come from Nick-PY0/BoardLens releases and are checksum-verified. Desktop keeps a rollback copy and preserves settings, engines and runtime. Android also checks the package identity, version and signing certificate. A desktop restart requires pairing the companion again.
